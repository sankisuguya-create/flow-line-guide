# flow-line-guide

学校行事の**導線**を、児童と職員に見せて説明するためのウェブ資料集。
運動会・音楽会などの「どこに並び、どう動き、どこへ戻るか」を、止められる・巻き戻せるアニメーションで示す。

紙の隊形図では伝わらない「時間の流れ」と「自分ひとりの動き」を扱うことが目的。

素材（物・場・操作UI）の集約先も兼ね、計画書から資料を生成できる（[docs/hub.md](docs/hub.md)）。
**校舎・プールの間取りを置くため、このリポジトリは非公開で運用する。**

---

## 構成

```
flow-line-guide/
├─ README.md
├─ docs/
│   ├─ hub.md        素材の集約と生成の仕組み（space.json・plan.json の書き方）
│   ├─ kikaku.md     共通規格の設計メモ（3層・型の見分け方・落とし穴）
│   └─ tsuika.md     資料を1本足す手順
├─ objects/          物（実寸mmの絵）。いまは desk-layout の複製
├─ spaces/<場>/      場（実寸mの区画・点・通路）
├─ core/             操作UI（再生部・見た目・ひな形）
├─ plans/<行事>/     中身（計画書から起こしたデータ）
├─ tools/            build.mjs（生成・検査）／check.mjs（撮影）／align.html（間取り合わせ）
└─ gas/<行事>/       配る1ファイルHTMLと GAS配信一式
```

行事が増えたら `gas/ongakukai/` のように階層を1つ足す。
**階層は行事までで止める。** 学年でさらに分けると、全学年共通の資料の置き場が歯抜けになる。

各 `gas/*/<場面>.html` は**単一ファイルで完結**する。外部CSS・外部JS・外部画像を一切使わない。
ダブルクリックでブラウザが開けば動く。オフラインでも動く。

`guides` 版はGAS版とCSS 2行しか違わず、GAS版も手元のブラウザで開けるため廃止した。
今後は `gas/` だけを正本とし、二重管理による反映漏れを防ぐ。

## 命名

`gas/<行事>/<場面>.html`

例：`gas/undokai/nyutai.html` / `gas/ongakukai/idou.html`

ローマ字・小文字で命名する。行事ごとにプロジェクトが分かれるので、行事の接頭辞は付けない。

## 使う

### 手元で開く

`gas/<行事>/<場面>.html` をブラウザで開くだけ。

### 児童・職員に配る

`gas/<行事>/README.md` の手順で Google Apps Script のウェブアプリとして公開する。
URLをClassroomに貼れば児童はクリックするだけで開ける。
Classroomの資料としてHTMLファイルを添付する方法は、児童側でダウンロードが必要になり使えない。

## 操作（資料に共通）

| ボタン | 動き |
|---|---|
| ▶ / ‖ | 再生・停止 |
| ▶▶ / ◀◀ | 押している間だけ早送り・巻き戻し |
| じかん | どこへでも飛べる。未再生の先へも進める |
| はやさ | 入退場は ×0.25〜×2、リレーは ×0.125〜×1 |
| ≡ | 操作パネルの開閉。畳むと図が全幅になる |

## 収録している資料

### 水泳 4年 1回目の動き（`gas/suiei/dai1ji.html`、生成）

`plans/suiei/dai1ji.json` から生成。4クラスと見学者がプール周りを同時に動く。「だれを見る」で自分の組だけを追える。地図は**仮**（配置図・写真で `align.html` を使って確認済にする）。

### 運動会 3年 入場・前つめ・退場（`gas/undokai/nyutai.html`）

場面は3つ。

- **入場**：テントから入場し、トラック内側の隊形に並ぶまで。最終回戦が先頭。
- **前つめ**：1回戦が出る → 残りの列が1つ前に詰める、の繰り返し。
  出た回戦は出発ブロックで消え、走り終わりブロックに現れる。
- **退場**：隊形からテントへ消えるまで。1回戦が先頭。

6枚1組（2列×3行）の隊列が形を保ったまま移動する。長方形1つが4人。

### 運動会 3年 半周リレーの動き方（`gas/undokai/relay.html`）

1人の児童の動きを最初から最後まで追える。
未走列 → 次走待ち場所 → レーン → 走る → 走り終えた列。
「れい」で通常・失敗例・作戦の違い・デッドヒート・7人チームの再走を切り替えられる。
