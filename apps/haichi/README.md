# 配置図

授業や活動の前に、**場所のどこに何を置くか**を教室の大画面モニターに映して見せる道具。
homeroom-tools の「机の配置図」（apps/desk-layout）をそのまま移し、場所を足した。
`dist/Index.html` をブラウザで開くだけで動く。サーバも名簿も使わない。外部通信なし。

## 場所

| 場所 | 中身 |
|---|---|
| 机の上 | 用具の配置・フック・しまう物・横から見た図・4人・いす（机の配置図と同じ） |
| 教室・体育館・運動場 | 7×9m／20×30m／40×60m の床に、用具・人・列・矢印 |
| 場（`assets/spaces/<場所>/`） | プールエリアなど。壁・扉・階段は space.json から描く（導線資料と同じ地図）。体育館の用具・人・列・矢印を置ける |

体育館の用具のうち **跳び箱（3〜8段）・ロイター板・マット（6号／9号、取っ手あり／なし）・厚いマット（40／50cm）・コーン** は
立体（`assets/objects/gym/mesh.js`）を地図用の見方（床は真上のまま、高さを上へ0.5倍）で描く。回すと立体のほうを回すので、高さはいつも画面の上へ出る。

足した物（`assets/objects/desk/extra.js`、寸法は一般的な製品の値で仮）：
- 体育：ハードル・高跳びのバー・フラフープ・長縄・得点板・ボールかご・ビブス・マット運搬車
- 印：スタートライン・ゴールライン・テープの印・番号マーカー（文字を書ける）・旗
- 人と組：組のまとまり（1〜4組の色＋名札）・先生・見学のいす
- 教室：机の島（4台・6台）・コの字・大型モニター・作品の机・掲示板・ロッカー
- 行事：長机（立体）・パイプいす（立体、1脚／5脚）・テント・放送台・演台・ひな壇

表示の切り替え：床の色（配置ごと）、輪郭を太く、場所の名前（場の区画名などの文字。方位は残る）。後の2つは端末に保存。

## 使い方

1. 上の「場所」を選ぶ → 活動カードを押す → 全画面の配置図
2. `左右反転`・`ふりがな`・`大きく映す`（机の上では `1人／4人`・`横から見た図`・`いす` も）
3. カードの「なおす」で編集。右のパレットから足し、ドラッグで動かす。選んだ物は「回す」「名前を出す」「いちばん上へ」「けす」、段数・大きさ・色の切り替え
4. 印刷：見せる画面の「印刷」はいま映している形のまま1枚（Ctrl+P でも同じ）。えらぶ画面の「まとめて印刷」は、いまの場所の配置を選んで1つ1枚ずつ。
   紙は A4。向きは図が大きく刷れるほうを自動で選ぶ。上に活動名（ふりがなの設定に従う）と日付の記入欄（　月　日（　））
5. 保存はこの端末のブラウザ（`haichi.v1`）。別の端末へは「データの書き出し・読み込み」のJSONで移す。机の配置図で書き出したJSONも読み込める

## 部品と正本

`src/Index.html` の `/* @include 名前 */` を `scripts/build.mjs` が差し込んで1ファイルにする。名前と正本の対応は `scripts/parts.mjs`。

| 部品 | 正本 |
|---|---|
| 物（机・教室・体育館・運動場） | `assets/objects/desk/data.js`・`draw.js` |
| 体育館の用具の立体・置く物 | `assets/objects/gym/mesh.js`・`items.js` |
| 場の床 | `assets/spaces/*/space.json`（`extends` を持つ行事用の上乗せは出さない）。描き方は `src/scenes.js` |
| 画面・見た目 | `src/app.js`・`src/style.css`・`src/tokens.css`（中立の色は `assets/ui/base.css`） |

```bash
node apps/haichi/scripts/build.mjs           # src → dist
node apps/haichi/scripts/build.mjs --check   # dist が古いと止まる
node apps/haichi/tests/test-app.mjs          # 不変条件
node apps/haichi/scripts/screenshot.mjs <出力先>   # 画面を撮る（playwright が要る）
```

設計の理由は [spec.md](spec.md)。
