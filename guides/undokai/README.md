# 運動会 ─ GASウェブアプリとして公開する手順

このディレクトリで**GASプロジェクト1つ**。運動会の資料だけが入る。
他の行事は別プロジェクトにする。方針は `../README.md`。

## 1. プロジェクトを作る

1. https://script.google.com を開き「新しいプロジェクト」
2. プロジェクト名を「運動会 の しりょう」に変更

## 2. ファイルを4つ用意する

エディタ左の「ファイル」＋ボタンから追加します。HTMLは「HTML」を選ぶこと。

| GAS上のファイル名 | 貼りつける内容 |
|---|---|
| `コード.gs`（既定のもの） | `Code.gs` の中身（既存の `myFunction` は消す） |
| `index`（HTML） | `index.html` の中身 |
| `nyutai`（HTML） | `nyutai.html` の中身 |
| `relay`（HTML） | `relay.html` の中身 |

ファイル名は拡張子なしで入力します（GASが自動で `.html` を付ける）。
`Code.gs` の `PAGES` がこの名前を `file` で参照しているので、綴りを変えないこと。

## 3. デプロイ

1. 右上「デプロイ」→「新しいデプロイ」
2. 種類の選択（歯車）→「ウェブアプリ」
3. 設定
   - 説明：任意
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**同じドメイン内の全員**
4. 「デプロイ」→ 初回は承認画面が出るので許可
5. 表示された **ウェブアプリのURL**（`.../exec` で終わる）を控える

## 4. 児童へ共有

- そのURLをClassroomの「資料」にリンクとして貼る
- 児童はクリックするだけ。もくじから資料を選べる
- 個別に直接開かせたい場合
  - 入退場・前つめ：`（URL）?p=nyutai`
  - リレー：`（URL）?p=relay`

`?p=` のキーは `Code.gs` の `PAGES` の `key`。**いちど児童に配ったら変えないこと。**
変えると配布済みのリンクが切れる。ファイル名（`file`）とは別物なので、
ファイル名だけなら変えても配布済みリンクは生きる。

## 5. 資料を1本足すとき

1. このディレクトリに `<場面>.html` を作る（`../../docs/tsuika.md`）
2. `Code.gs` の `PAGES` に1行足す
3. GASエディタにHTMLファイルを追加し、`Code.gs` を貼り直す
4. 「デプロイを管理」→ 新バージョン

**もくじ（`index.html`）は触らない。** `PAGES` から自動で組み立てている。

## 6. 更新するとき

HTMLを直したあと、「デプロイ」→「デプロイを管理」→ 対象の鉛筆アイコン →
バージョン「新バージョン」→「デプロイ」。**URLは変わりません**。

「新しいデプロイ」を選ぶとURLが変わり、児童に配ったリンクが古いままになるので使わないこと。

---

## 確認が必要な点

- **アクセス範囲**：「同じドメイン内の全員」は児童のGoogleアカウントでのログインが前提です。ログイン状態が不安定な場合は「全員」に変更が必要ですが、URLを知る誰でも閲覧できる状態になります。
- **表示の高さ**：GASは内容をiframeに入れて表示します。本資料は全画面レイアウトなので、まず自分の端末で開いて縦が潰れていないか確認してください。潰れる場合は各HTMLの `html,body{ ... height:100% ... }` を `height:100vh` に変えると直ります。
- **端末**：CZ1104FM2A（4GB機）でも動く軽さで作ってありますが、初回は実機で再生を確認してください。
