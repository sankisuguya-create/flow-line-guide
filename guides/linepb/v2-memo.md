# v2 着手時の覚書

v1（`rule.html`、2D・SVG）は完成扱い。v2 は添付動画のような演出（暗い背景・光・粒・章見出し・カメラ移動）を試行する。

## 利用者の指定（2026-11-15）
- マスコット：`ref/mascot-variants.png` の左上（緑・顎は白・目は白黒しま）の **肌の色を銀色** にした版。
  - 解釈（着手時に確認）：緑の頭・胴 → 銀。顎の白、目、胴の白い模様、アンテナの形は維持。手足の濃い緑を残すか、濃い銀（ガンメタ）にするかは未定。
- 平面のマップ（v1 相当）に **加えて**、立体表示を持つ。
  - 人＝四角柱（チーム色＋A〜E）、しんぱん＝緑の四角柱。
  - ボール＝球。

## 技術方針（v1 時点の見込み）
- Three.js でブラウザ内に描画し、時間を1コマずつ進めて撮影 → ffmpeg で mp4。コマ落ちなく、何度でも同じ結果になる。
- 動き・字幕・ファウルのデータは v1 の `SCENES` を共有する（2D と 3D で二重に持たない）。
- 配布は mp4。3D の HTML を4GB の Chromebook で動かすのは重い見込み（未計測）。
- 最初に1場面（ゴール）だけ作り、見た目と重さを確認してから広げる。
